# Russian translation and polish

Use this when the user wants text translated into Russian or an existing Russian text polished: documentation, an article, a game, or interface copy.

1. Establish the register first: who reads it, formal or informal address, and whether the terms are already fixed. Never overwrite the original file — write next to it or into a new one.
2. Build a short canon before translating: the glossary for recurring terms (one term, one word), the address form (ты/вы), and what stays untranslated (code, tags, placeholders, product names).
3. Translate in batches of one section or about forty lines; keep Markdown structure, tags and placeholders byte-identical.
4. Polish in passes: P0 meaning, P1 grammar, P2 term consistency, P3 word order, P4 style, P5 stiffness, P6 final read. Fix a whole class of mistake across the file in one pass instead of one occurrence at a time.
5. For every stiff sentence, write three variants and pick the one that sounds like a person wrote it. Report the glossary and the passes you applied.
