# 09-personal · Личные данные

Скиллы:

- [`health.md`](health.md) — a lab sheet, scan report, or family health record
- [`dreams.md`](dreams.md) — a dream or nightmare is told and asks to be read
- [`photo-ocr.md`](photo-ocr.md) — a photo arrived and the message has only paths

## Перенос

`photo-ocr` отправляет изображение на публичный хост и берёт OCR-ключи из проекта; без явного согласия не использовать. `health`/`dreams` — чувствительные данные.
