# Прочитать текст с фотографии (когда в чат пришли только пути)

Когда: пользователь приложил фото или скриншот, а текста в сообщении нет — модель получает
путь и метаданные, но не картинку.

1. Оцени файл: имя, размер, размеры. Фото с камеры — это JPEG; `png_tool.py` проекта умеет
   только PNG, а `PIL` в python обычно не установлен, поэтому ресайз и кроп недоступны.
2. Выложи файл на временный публичный хост. Работает litterbox:
   POST `https://litterbox.catbox.moe/resources/internals/api.php`,
   поля multipart: `reqtype=fileupload`, `time=1h`, `fileToUpload=<файл>` → в ответ ссылка.
   Загрузку делает python (у него есть сеть), потому что `http_request` не умеет отправлять файл,
   а `fetch` в шелле отсутствует.
3. Распознай по ссылке:
   `https://api.ocr.space/parse/imageurl?apikey=<ключ>&url=<urlencoded>&language=rus&OCREngine=1&scale=true&filetype=JPG`
   Ключи перечислены в `ocr.py` проекта. Бесплатный `helloworld` часто отдаёт 503 —
   берём рабочий из списка. Таймаут ставь длинный (120—240 с).
4. Ответ — JSON: текст в `ParsedResults[].ParsedText`. Движки 1 и 2 обычно дают один и тот же текст.
5. Убери за собой: ссылка litterbox живёт 1 час, копию на своём FTP (`remote_delete`) удали сразу
   после распознавания. Наружу уходит только само изображение.
6. Широкое фото (4000 px) читается хуже: OCR берёт крупный текст (заголовки, обложки),
   мелкий может пропасть. Если текста мало и он неполный — попроси пользователя прислать
   фотографию фрагмента крупнее.
