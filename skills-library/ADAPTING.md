# Адаптация скиллов

## 1. Контракт файла

- UTF-8, один `.md` на скилл, имя файла = имя скилла.
- 2–40 символов, lowercase `a-z`, `0-9`, `-`, первый символ — буква.
- До 12 000 символов.
- Первая строка `# Title`; первая строка, начинающаяся с `Use this`, становится кратким описанием в каталоге.
- YAML front matter допустим, если закрыт.
- Скилл не добавляет инструмент, разрешение или MCP-сервер. Он только описывает порядок вызовов.

## 2. Замена инструментов

| В этих скиллах | В целевом агенте |
|---|---|
| `run_command` | shell/exec с ограничением рабочей папки |
| `read_file`, `write_file`, `edit_file` | файловые инструменты |
| `grep`, `glob`, `list_dir` | поиск и обход файлов |
| `http_request` | HTTP-клиент с белым списком |
| `browse_page` | браузер/скриншот |
| `layout`, `network_card`, `ascii_art`, `chart` | рендер карточки/чата; если нет — верни Markdown/`<pre>` |
| `open_file` | открытие файла в системе/просмотрщике |
| `load_tools group=...` | загрузка группы инструментов; если групп нет — удали строку |
| `use_skill` | включение скилла; если нет — просто прочитай файл |
| `scan_skill`, `review_skill` | локальный аудит/сканер скиллов |
| `net_audit`, `capture_dump`, `read_dump` | сетевые инструменты/дампы |
| `render_video`, `edit_video`, `download_video` | видео-пайплайн; если нет — оставь только ASCII/HTML |
| `install_apk`, `shizuku_exec` | Android/adb; на не-Android удалить |
| `remote_put`, `ssh_exec` | удалённый ПК/SSH |

Если инструмента нет, не выдумывай его. Перепиши шаг под имеющийся инструмент или сократи скилл.

## 3. Пути

- `/storage/emulated/0/CEditNeuro/skills` — телефонный app-scope CEditoNeuro.
- `.ceditneuro/skills` — проектный scope.
- `research/`, `video/`, `.ua/`, `learn/`, `downloads/` — рабочие папки CEditoNeuro.
- Замени их на пути целевого проекта. Не оставляй абсолютный путь к чужому телефону.

## 4. Группы и зависимости

В `manifest.json` есть `groups` и `requires_skills`. Если скилл требует другой скилл, перенеси оба или объедини процедуру. Если группа инструментов отсутствует, убери `load_tools` и замени вызовы.

## 5. Что адаптировать в первую очередь

- **Android**: `android-apk`, `android-app`, `android-compose`, `android-debug`, `android-ui` — заменить пакет, Gradle, SDK, adb/Shizuku, `install_apk`.
- **CEditoNeuro-specific**: `second-monitor`, `crew`, `rrsi`, `find-skills`, `video-download`, `web-to-app` — переносить только при наличии аналогов.
- **REA**: `rea` требует Node `^22.23.4 || ^24.22.1 || >=26.12.1` и MCP; на телефоне не запускается. Для телефона оставь `reverse-engineering`.
- **Genealogy**: `genealogy` требует файловых инструментов и `http_request`; `browse_page` можно заменить ручным браузером. CAPTCHA и вход — только человек.
- **Security**: `skill-security` — рубрика; без `scan_skill` адаптируй правила в собственный аудит.
- **ASCII**: `ascii-studio` использует `ascii_art`; если инструмента нет, оставь шаблон и `render_video`/Markdown.

## 6. Проверка после переноса

1. Скилл ≤ 12 000 символов.
2. Все имена инструментов существуют в целевом агенте (или явно помечены как отсутствующие).
3. Нет опасных команд, скрытых установок и обхода разрешений — либо шаг удалён, либо это явный сценарий на собственном ПК с подтверждением (например, REA).
4. Нет ключей, паролей, токенов, абсолютных путей к чужому устройству.
5. Один пробный запуск на маленькой задаче; результат проверен.
